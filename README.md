# Brick Breaker

A simple 2D Brick Breaker game developed in Unity to learn game development fundamentals.

## Features
- Paddle-controlled gameplay
- Ball movement with collision physics
- Brick destruction mechanics

## Technologies Used
- Unity
- C#

## What I Learned
- Implementing gameplay mechanics in Unity
- Collision detection and physics
- Game object interactions
- Building simple 2D games using C#
